# Patsy Project Working Rules

## Screenshot / picture issue rule
When the user sends a screenshot or photo showing a build, UI, setup, or app problem, inspect the image and fix the identified project/code issue immediately when it is safe and technically possible. Do not ask for permission to fix an obvious issue.

Preserve approved artwork and requirements; do not redesign approved assets while fixing technical faults. If a fix requires an action only the user can perform on their device, make all code/package fixes first, then give the shortest exact next step.
