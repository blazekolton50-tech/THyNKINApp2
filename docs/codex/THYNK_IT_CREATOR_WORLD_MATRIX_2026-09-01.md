# THyNK-IT Creator World Matrix — 1 September 2026

Status: pre-code source of truth for adaptive workspace content
Branch: `chatgpt/codex-ready-2026-09-01`
PR: #41 Draft/unmerged

Purpose: define what the adaptive THyNK-IT editor should become after a creator chooses what they want to make. This is content/configuration guidance, not proof that every tool is already implemented.

## Routing rule

- Shared-canvas/page work -> THyNK-IT adaptive Creator Editor.
- Audio playback/creation/editing -> THyNK Music.
- DJ work -> THyNK Music / DJ Studio.
- Video playback/creation/editing -> THyNK Video.
- Reels/Shorts selected from Social -> THyNK Video.
- Global account, project identity, autosave, storage, permissions, Patsy assistance and shared navigation remain common.

Bundled fonts require verified redistribution licensing before production packaging.

### Template verification

Every template family must carry a state:

- `REFERENCE_ONLY`
- `VERIFIED_METADATA`
- `VERIFIED_ASSET`

Only `VERIFIED_ASSET` is eligible to be presented as a production bundled template. React/Tailwind donor layouts start as `REFERENCE_ONLY`.

## Progressive UI rule

The editor should never show every control above at once.

1. Project type chooses the workspace configuration.
2. Workspace config chooses visible shared tools.
3. Subject panels expose project-specific concepts.
4. Selecting an object narrows the property panel again.
5. Beginner shortcuts stay visible first; advanced tools expand on demand.

Examples:

- Fashion Collection -> garments/fabric/swatches/measurements + shared draw/text/layers/guides.
- Magazine -> pages/spreads/columns/margins/masthead + shared text/media/layers/guides.
- CV -> document sections/headings/tables + restrained formatting; no animation/audio clutter.
- Instagram Post -> templates/photo/text/stickers/brand/background/effects/resize.
- Reel -> route to THyNK Video.
- DJ Set -> route to THyNK Music / DJ Studio.

## Creator opportunity / discovery intent

Project metadata should eventually support:

- discipline
- project type
- skills used
- creator role
- collaboration status
- feedback permission
- remix permission
- visibility
- portfolio inclusion

Discovery should rank for relevance/quality/discipline signals, not raw follower count alone. Under-16 public discovery, messaging and collaboration remain disabled until the dedicated age/privacy/safety design is implemented and verified.

## Build order from this matrix

1. Adaptive workspace contracts/configuration layer.
2. Fashion, Magazine, Office, Art and Social as proving configurations.
3. Shared resource metadata for templates/palettes/typography.
4. Hub/project-type selection -> correct workspace.
5. More Creator Worlds added as configurations.
6. React/Tailwind donor packs generated world-by-world.
7. Asset verification pipeline promotes approved donor/templates/fonts into native production resources.
8. Separate Music/Video plans extend their existing specialist engines.
